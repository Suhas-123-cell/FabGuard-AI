# Reviewed reference corpus

`corpus.json` contains short, manually reviewed paraphrases with source and
section provenance. FabGuard indexes these passages; it does not redistribute
the linked publisher documents. The UORED paper is CC BY 4.0. The SKF and
Timken documents remain linked publisher material and are represented only by
brief project-authored summaries.

The passages provide general inspection guidance. They do not create
machine-specific alarm limits or authorize maintenance work.
